# Implementation Plan - Apex Marketing Command Center 📣🚀

Transforming the "Broadcast" feature into a professional, multi-channel Marketing Command Center. This evolution enables one-click campaign deployment across Instagram, Facebook, WhatsApp, and Email with deep ROI tracking.

## User Review Required

> [!IMPORTANT]
> - **Integrations**: This system will require connecting Meta Business and Google (Gmail) accounts via OAuth to enable actual social publishing and email sending.
> - **Tracking**: Links generated by the campaign builder will include UTM parameters to attribute revenue back to specific marketing channels.

## Proposed Changes

### 1. Database Evolution (Supabase) 🗄️

#### [NEW] Marketing Schema
- **`marketing_campaigns`**: Stores campaign metadata (name, type, product_id, status, scheduled_at).
- **`campaign_channels`**: Links specific content and status (Ready/Failed/Published) for each channel (IG, FB, WA, Email).
- **`customer_segments`**: Stores rules for dynamic audience grouping (e.g., "VIP", "Abandoned Cart").
